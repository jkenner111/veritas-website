# Blog Posts

This directory contains MDX blog posts managed by the admin agent.

Each file is a blog post with frontmatter:

```mdx
---
title: "Blog Post Title"
date: "2026-05-28"
summary: "Brief description of the post"
author: "Jack Kenner"
---

Your blog content here...
```

Posts will be listed on the `/blog` index and available at `/blog/[slug]`.
